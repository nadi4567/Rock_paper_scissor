# Rock Paper Scissors Game 🎮  

A simple **Rock Paper Scissors** game built with **HTML, CSS, and jQuery**. The game allows the user to play against the computer in a 5-round match. At the end of the game, a **congratulations screen** appears with a flashing brightness effect if the user wins!  

## 🔹 Features  
✅ Interactive **Rock, Paper, Scissors** gameplay  
✅ Randomized computer choice for fair play  
✅ Keeps track of **rounds and scores**  
✅ **Bright flashing effect** when the user wins  

## 🖥️ How to Play  
1. Click **Rock**, **Paper**, or **Scissors** to make your move.  
2. The computer randomly selects its move.  
3. The winner is decided based on the standard game rules:  
   - **Rock beats Scissors**  
   - **Scissors beats Paper**  
   - **Paper beats Rock**  
4. The game lasts **5 rounds**.  
5. If the player wins more rounds than the computer, a **"Congratulations!"** screen with a **flashing effect** appears.  

## 📜 Technologies Used  
- **HTML** – Structure the game  
- **CSS** – Styling and animations  
- **JavaScript (jQuery)** – Game logic and interactivity  

## 🎨 Special Effects  
- A **flashing brightness effect** appears when the user wins.  
- Smooth animations using **jQuery's fadeIn() and fadeOut()** methods.
